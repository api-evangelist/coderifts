CodeRifts provides a platform for verifying and documenting AI-driven actions. It offers a guarded tool table, action verification APIs, and detailed documentation for developers to integrate provenance and compliance checks into their workflows. The service includes a web interface, API endpoints, pricing plans, and open-source tooling to ensure transparent decision-making for AI agents.

**Areas:** Company · Artificial Intelligence · Verification · Compliance · Platform

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for CodeRifts: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
